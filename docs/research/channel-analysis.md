## 2. 관측에서 나온 결정적 사실 4가지

기획서를 다시 손봐야 할 만큼 중요한 것들이다. 전부 이 채널을 직접 열어 확인한 1차 관측이다.

### ① 콘텐츠가 두 갈래이고, 한쪽은 조회수가 숨겨져 있다 ★가장 중요

채널이 두 제품 라인으로 나뉜다.

- **코스 콘텐츠** — 「スパルタ韓国語 初級1/初級2/中級」 Unit별 체계 강의. **대부분 "회원 전용(会員専用)"** 이라 **공개 조회수가 표시되지 않는다.** 롱폼과 쇼츠(丸暗記 시리즈) 양쪽에 다 있다.
- **공개 단독 콘텐츠** — 한드라 한국어, 발음 팁, 단어 공부법, 한자어 규칙 등. 조회수가 **공개된다.**

관측된 공개 영상 조회수 예시:
- 韓国語単語勉強は、こう始めてください｜漢字語ルール10選 — **4.1천회**
- 韓ドラ『鉄槌教師』で学ぶ韓国語 — **1.9천회**
- 長い文を自然に話す練習 [中級II Part5] — **374회**
- Unit47 -는 중 (공개된 코스 영상) — **224회**

**제품에 주는 함의** — 자사 채널의 간판 콘텐츠(코스) 상당수가 **공개 데이터로 성과 측정 불가**다. 회원 전용 영상은 조회수가 가려져 있어 YouTube Data API로도 통계가 안 나올 가능성이 높다(본개발 때 우리 채널 인증 토큰으로 확인 필요). 따라서 기획서 §6의 "자사 유사 영상 확인"은 **제목·주제 매칭까지는 되지만, 그 영상들의 성과 비교는 코스 콘텐츠에 대해선 안 된다.** 이건 우리가 몰랐던 제약이다.

### ② "조회수 ÷ 구독자"가 이 채널에서 실제로 깨진다

공개 영상 조회수가 200~4,100인데 구독자가 10,200이다. 구독자 대비 비율이 **0.02~0.4**로 전부 1 미만이다. 코스 영상은 소수 열성 회원에게 전달되는 구조라 이 비율이 낮은 게 당연하지, "저성과"가 아니다. **벤치마크에서 권고한 "채널 내부 기준선 대비 배수"로 바꿔야 할 이유가 가설이 아니라 실측으로 확인됐다.**

### ③ 쇼츠와 롱폼이 섞여 있고, 쇼츠가 더 잘 나온다

- 쇼츠 45개 이상 존재. 공개 쇼츠 조회수는 **1,900~3,200으로 고르게** 나온다.
- 반면 공개 롱폼은 224~4,100으로 **편차가 크다.**
- 즉 쇼츠가 공개 롱폼보다 조회수가 높고 안정적이다.

**제품에 주는 함의** — 쇼츠와 롱폼을 한 기준선에 묶으면 **모든 롱폼이 저성과로 오탐**된다. 벤치마크에서 "우리가 직접 판단해야 한다"고 남긴 쇼츠/롱폼 분리 처리 문제가, 대상 채널에서 **실제로 발생하는 문제**임이 확인됐다. → 기준선은 쇼츠/롱폼 분리 계산이 사실상 필수다.

### ④ 소형·니치 채널 — 벤치마크가 경고한 취약 구간에 정확히 위치

구독자 1만, 공개 영상 조회수 수백~수천. 벤치마크에서 "Viewstats조차 10K 미만에서 데이터가 제한적", "짧은 비교 창에서 점수 왜곡"이라 경고한 바로 그 구간이다. 표본이 얇아 outlier 오탐이 잘 나므로, 비교 창을 넉넉히(예: 최근 20~30개) 잡고 회원 전용 영상을 기준선 계산에서 제외하는 설계가 필요하다.

## 3. 콘텐츠 주제 인벤토리 (관측된 것)

기획서 §6 "자사 유사 영상 확인"의 매칭 대상이 될 자사 주제 축이다.

- **문법 Unit 강의**(코스, 회원 전용 다수) — 조사, 敬語, 과거형, 지시어, 어미(-지요/-죠, -게, -기 위해서) 등 교과서적 문법 순서
- **발음** — 안녕하세요 억양, 듣기 안 되는 이유
- **어휘/한자어** — 漢字語 규칙, 単語 공부법
- **한드라로 배우는 한국어** — 실생활 표현
- **한국 생활/여행 팁** — 현금 안 되는 문제 등 (쇼츠)

## 4. 확정된 기획 결정 (사용자 승인 완료)

### 결정 A — 에버그린 & 상승추세 처리: (A)+(B) 혼합 채택 [2026-07-21 승인]

- **(B) 대리지표 즉시 노출** — "업로드된 지 오래됐는데 현재 조회수가 채널 기준선을 넘는 영상"을 **"에버그린 후보"** 라는 라벨로 1일차부터 표시. **"에버그린"이라 단정하지 않는다** — 급등 후 식은 영상과 아직 구분 안 되기 때문.
- **(A) 스냅샷 축적 후 승격** — 오늘부터 일일 스냅샷을 쌓고, 감쇠 기울기가 계산되면 "에버그린 후보"를 검증된 "에버그린"으로 승격. MVP UI에는 "데이터 수집 중" 상태로 둔다.
- 근거: 벤더에 검증된 에버그린 지표가 없어 우리가 설계해야 하는데(벤치마크 §2-D), 진짜 감쇠 기울기는 스냅샷 2~3주가 전제라 3주 MVP 안에 검증 불가. 그래서 검증 없이도 내보낼 수 있는 대리지표를 먼저 쓰되 라벨로 불확실성을 표시.

### 조사에서 나온 시사점 (제품 설계에 반영)

1. **직접 경쟁군이 두 세그먼트로 갈린다** — ① 체계형 롱폼 강의(토미·seemile·코리안테나, 스파르타와 정면), ② 쇼츠 기반 학습(サットン). 대시보드에서 이 둘을 구분해 트래킹할 가치가 있다.
2. **화자 정체성이 차별화 축** — "네이티브가 일본어로"(다히·회사원A) vs "일본인 학습자 시점"(토미·미사닝). 스파르타는 전자.
3. **콘텐츠→교재/앱→학원 수익 확장이 공통 패턴** — JOO·TTMIK·seemile·코리안테나. spartakorean.com과 같은 퍼널이라 직접 참고감.
4. **카테고리4가 학습 채널의 상단 퍼널** — 이중자막 K-culture 채널이 "한국 관심 → 한국어 학습" 유입 경로. 교육 채널이 아니어도 알고리즘상 강한 인접군이다.

> 구독자 "확인 불가" 항목(다히·サットン·코리안테나·Korean Unnie·あゆたび·ミョリム 등)은 채널 페이지 JS 렌더링 때문에 웹에서 값이 안 나온 것으로, 본개발 때 API `channels.list`로 즉시 채워진다.

## 6. 평가 기준 실데이터 검증 — 평균 vs 중앙값, 쇼츠/롱폼 분리 (2026-07-21 확정)

앞서 "본개발 때 실데이터로 정하자"고 미뤄뒀던 두 결정을, 자사 채널의 **실제 공개 조회수를 수집해 지금 확정**했다. 표본: 공개 롱폼 86개, 공개 쇼츠 45개(회원 전용은 조회수 가려져 제외 — 어차피 기준선에서 빼야 하는 것들). 반올림 조회수지만 아래 격차는 반올림 오차를 훨씬 넘어 결론이 바뀌지 않는다.

### 결정 1 — 평균이 아니라 **중앙값(median)** 을 기준선으로 [확정]

| | 롱폼(n=86) | 쇼츠(n=45) |
|---|---|---|
| 평균(mean) | 3,295 | 3,724 |
| 중앙값(median) | **845** | **2,300** |
| 평균/중앙값 | **3.9배** | 1.6배 |
| 최댓값 | 97,000 | 42,000 |

**결정적 증거** — 롱폼에서 평균이 중앙값의 **3.9배**다. 97,000·31,000·19,000 같은 소수 대박 영상이 평균을 끌어올린 것이다. 그 결과가 뒤집힌다.

- 평소보다 확실히 잘 나온 영상(조회수 1,900, 상위 25%)을 재보면 **중앙값 기준 2.25배(고성과, 맞음)** 인데 **평균 기준 0.58배(저성과로 오판)** 가 된다.
- 즉 평균을 기준선으로 쓰면 **꽤 잘한 영상이 "평균 미달"로 찍힌다.** 정확히 벤치마크에서 경고했고 서드파티 OutlierKit도 지적한 오작동이다("one massive video can distort the average").

vidIQ 문서는 "average"라 쓰지만, 우리 채널처럼 대박 편차가 큰 소형 채널에서는 중앙값이 옳다. → **중앙값 채택.**

### 결정 2 — 쇼츠와 롱폼 기준선을 **분리 계산** [확정]

- 롱폼 중앙값 845 vs 쇼츠 중앙값 2,300 — **쇼츠가 2.7배** 높다. 스케일이 근본적으로 다르다.
- 둘을 합쳐 하나의 기준선(공통 중앙값 1,600)으로 재면:
  - 평범한 롱폼(845)이 **0.53배 → 저성과로 오판**
  - 평범한 쇼츠(2,300)가 **1.44배 → 고성과로 오판**
- 이건 잡음이 아니라 **체계적 편향**이다. 합치면 모든 롱폼이 억울하게 깎이고 모든 쇼츠가 부풀려진다. → **분리 계산 채택.**

> 크로스 카테고리 안전성 — 기준선은 채널마다 따로 계산하므로(각 채널이 자기 자신과 비교), 경쟁군을 영어권·언어교육 일반까지 넓혀도 이 로직은 그대로 성립한다. 쇼츠/롱폼 분리도 채널·유형별로 독립 적용된다.

참고: [OutlierKit — Outlier Scores](https://outlierkit.com/resources/outlier-scores/), [vidIQ Outliers](https://support.vidiq.com/en/articles/9660010-outliers)

## 7. "시장 검증됨" vs "우리 판단" 구분표

평가 기준의 각 항목이 시장에서 실제로 쓰는 것인지, 조사 기반으로 우리가 판단한 것인지 구분한다. 나중에 "이건 왜 이렇게 정했나"에 대한 근거로 쓴다.

| 항목 | 구분 | 근거 |
|---|---|---|
| 채널 내부 기준선 대비 배수(성과 배수/outlier) | **시장 검증됨** | vidIQ·Viewstats 공식 문서, 독립적으로 동일 설계 |
| 성과와 모멘텀(급상승) 분리 | **시장 검증됨** | vidIQ가 Outlier와 VPH를 별도 지표로 운용 |
| 키워드 채점 ≠ 영상 채점 | **시장 검증됨** | TubeBuddy weighted/unweighted 분리 |
| 검색량은 전부 추정치(절대치 불가) | **시장 검증됨** | vidIQ·TubeBuddy·KeywordTool 3사 자인 |
| **평균 대신 중앙값** | 우리 판단 → **실데이터 검증됨** | 자사 채널 평균/중앙값 3.9배 격차 + OutlierKit + 로버스트 통계 원칙 |
| **쇼츠/롱폼 기준선 분리** | 우리 판단 → **실데이터 검증됨** | 자사 채널 쇼츠/롱폼 중앙값 2.7배 격차. 벤더는 공개 안 함 |
| 회원 전용 영상 제외 | 우리 판단(관측 기반) | 자사 코스 영상 다수가 회원 전용이라 조회수 가려짐. 강제됨 |
| 에버그린 (A)+(B) 혼합 | **우리 설계** | 벤더에 검증된 에버그린 지표 없음 |
| VPH → VPD 대체 | 우리 판단(제약 기반) | 하루 1회 갱신 상한 때문 |

> 한 줄 요약 — **성과 배수라는 뼈대는 시장 표준이고, 중앙값·쇼츠분리는 원래 우리 판단이었으나 자사 실데이터로 검증됐다.** 회원제외·에버그린·VPD는 우리 상황(회원제 채널, 하루 1회 갱신)에서 나온 우리 결정이다.
